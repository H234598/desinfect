# P06.2 Rights Policy Implementation Plan

> Execute task-by-task with TDD, task review, and full regression gates.

**Goal:** No PDF, full text, or ZIP is materialized or published without a current reviewed decision from the authoritative rights register.

**Architecture:** `rights.py` owns strict policy/register parsing, deterministic decisions, and publication filtering. Storage contracts carry source and decision provenance. LFS/remote adapters re-resolve that provenance before every byte-producing operation. Storage Reference 1.0 remains readable through a deterministic 1.1 migration but is never payload-authorizing.

**Constraints:** Fail closed. No wildcard or source-only authorization. Raw RKI metadata is evidence only. Rights register remains human-reviewed and automatic-write denied. `codegraph` tool unavailable; structure traced once with `rg` and Context Mode.
