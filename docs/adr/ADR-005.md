# ADR-005
**Kontext:** Der tägliche Scheduler darf keine tägliche künstliche Repositoryaktivität erzeugen.

**Optionen:** A: täglicher Keepalive; B: nie Statuscommit ohne Inhalt; C: täglicher No-op, fälliger Wochenlauf darf Betriebsnachweis schreiben.

**Entscheidung:** C. Nur eine fachlich fällige Aufgabe darf einen No-document-Betriebsnachweis schreiben; tägliche Prüfung bleibt read-only.

**Rückroll- oder Migrationsweg:** No-document-Berichte in ein externes append-only Monitoring verlagern.
