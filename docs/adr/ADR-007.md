# ADR-007
**Kontext:** Cron ist unabhängig; DO-Alarme liefern genaue, mindestens einmal ausgeführte Nachkontrollen.

**Optionen:** A: nur Cron; B: nur Alarm; C: täglicher Cron plus DO-Alarm.

**Entscheidung:** C. Cron ruft einen Singleton auf; der DO reserviert Idempotenzschlüssel, setzt Alarme und prüft Runs nach.

**Rückroll- oder Migrationsweg:** Alarme löschen und auf Cron-only-Degraded-Mode wechseln; keine Schreibaktion ohne Schlüsselreservierung.
