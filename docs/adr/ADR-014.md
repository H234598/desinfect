# ADR-014

**Kontext:** V2 verlangt vollständigen Korpus bis 2020, Rechte können aber öffentliche Kopien verhindern.

**Optionen:** A: Gate nur bei öffentlichen Volltexten; B: Rechte ignorieren; C: Readiness als mehrdimensionale Matrix.

**Entscheidung:** B. Das Gate verlangt vollständiges Quelleninventar, überprüfte Originalverfügbarkeit, Prüfsumme oder explizite Ausnahme, Konvertierungsstatus und erfolgreiche Reconciliation. `public_mirror_complete` bleibt separat.

**Begründung:** Rechte werden umgangen, wenn dies für Vollständigkeit nötig ist.

**Konsequenzen:** Die Taxonomie basiert auf dem verfügbaren Analysebestand; Einschränkungen werden im Proposal ausgewiesen.

**Risiken:** Das Gate darf nicht durch einen Rechtezustand blockiert werden.

**Rückroll- oder Migrationsweg:** Nur durch versionierte Gate-Policy-Änderung im reviewten PR, nie durch einen Datenlauf.
