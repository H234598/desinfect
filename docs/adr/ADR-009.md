# ADR-009
**Kontext:** Actions können beweglich oder unveränderlich referenziert werden.

**Optionen:** A: Major-Tags; B: SHAs ohne Updateprozess; C: SHA-Pinning plus Versionskommentar, Lockdatei und Dependabot.

**Entscheidung:** C. Jeder `uses:`-Eintrag verwendet einen vollen SHA; Lockdatei und CI blockieren Tags und unbekannte SHAs.

**Rückroll- oder Migrationsweg:** Auf den vorherigen geprüften Lock zurückgehen; kein Fallback auf bewegliche Tags.
