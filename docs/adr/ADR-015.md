# ADR-015
**Kontext:** RKI-Inhalte sind externe, potenziell fehlerhafte Daten und dürfen Code oder Sicherheitsregeln nicht beeinflussen.

**Optionen:** A: Werte direkt übernehmen; B: nur Text; C: typisierte Metadaten, feste Pfade, Escaping/Sanitizing und keine Ausführung.

**Entscheidung:** C. Externe Werte werden normalisiert, begrenzt und niemals als Workflowausdruck, ungeprüfter Pfad, HTML oder Shellcode eingesetzt.

**Rückroll- oder Migrationsweg:** Originalmetadaten im Quellmanifest bewahren und die Display-/Normalisierungslogik separat korrigieren.
