# ADR-006
**Kontext:** GitHub Actions und Cloudflare benötigen App-Authentisierung.

**Optionen:** A: identischer Schlüssel; B: PAT; C: zwei getrennte aktive Schlüssel derselben App.

**Entscheidung:** C. GitHub Actions und Cloudflare erhalten getrennte App-Private-Keys und Rotationsfristen.

**Rückroll- oder Migrationsweg:** Betroffenen Schlüssel widerrufen, neu erzeugen, nur das zugehörige Secret ersetzen und Tokenfluss testen.
