# Git LFS und Speicher

Normale Websitequellen bleiben in Git. Große Binärartefakte verwenden ausschließlich konfigurierte
Speicherpfade und überprüfte Backendverträge. Pointer, Objekt und Metadaten müssen zusammenpassen,
bevor Verarbeitung fortgesetzt wird.
