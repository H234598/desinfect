# Interne und externe Wachhunde

Interne Pipelineprüfungen überwachen Laufzustände im Repository. Der externe Cloudflare-Wächter
prüft GitHub unabhängig davon. Beide melden Störungen; keiner ersetzt fachliche Freigaben oder
lockert Schreibgrenzen.
