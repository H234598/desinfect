# Diagnostics

Dieses Verzeichnis dokumentiert nur Diagnoseverträge. Laufbezogene Debugdaten werden redigiert als zeitlich begrenzte GitHub-Actions-Artefakte gespeichert und nicht committed.

Kanonische Eingaben bleiben schema-valide RunManifeste und `status.json`; generierte Job Summaries oder heruntergeladene Actions-Artefakte sind keine Statusquelle und kein Recovery-Checkpoint.
